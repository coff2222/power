Step-by-Step Guide

단계별 Gemini 연동 가이드

가장 유연하고 인기 있는 Continue 확장 방식을 중심으로 4단계로 연동해 보겠습니다.

01

Google AI Studio에서 무료 API Key 발급받기

소요 시간 1분

Gemini 모델을 VS Code에서 직접 호출하기 위해 Google AI Studio에서 무료 API Key를 발급받습니다. 일반 구글 계정만 있으면 신용카드 등록 없이 즉시 생성이 가능합니다.

발급 절차
  1. Google AI Studio API Key 페이지에 접속하여 로그인합니다.
  2. 화면 상단의 Create API key 버튼을 클릭합니다.
  3. 기존 Google Cloud 프로젝트를 선택하거나 신규 프로젝트 생성을 선택합니다.
  4. 생성된 AIzaSy... 형태의 키를 안전한 곳에 복사해 둡니다.
주의: 발급받은 API 키는 타인에게 공개되지 않도록 주의하세요 (깃허브 레포지토리 커밋 금지).
02

VS Code에서 Continue 확장 프로그램 설치하기

마켓플레이스

VS Code 좌측 액티비티 바의 확장 프로그램 아이콘()을 누르거나 단축키를 눌러 Continue를 검색합니다.

단축키 (확장 탭 열기) Ctrl + Shift + X (Windows/Linux)
Cmd + Shift + X (Mac)
검색 키워드
Continue - Codestral, Claude, and more

설치가 완료되면 좌측 사이드바에 새로운 재생 모양의 Continue 아이콘이 나타납니다.

03

config.json에 Gemini 모델 및 API 키 설정

핵심 설정

Continue 사이드바 하단의 설정 아이콘(⚙️)을 클릭하면 설정 파일(~/.continue/config.json)이 열립니다. 아래 설정을 복사하여 붙여넣고 발급받은 API 키를 입력하세요.

config.json (Gemini 설정) 
{
  "models": [
    {
      "title": "Gemini 1.5 Pro (Google)",
      "provider": "gemini",
      "model": "gemini-1.5-pro-latest",
      "apiKey": "YOUR_GEMINI_API_KEY_HERE"
    },
    {
      "title": "Gemini 1.5 Flash (초고속)",
      "provider": "gemini",
      "model": "gemini-1.5-flash-latest",
      "apiKey": "YOUR_GEMINI_API_KEY_HERE"
    }
  ],
  "tabAutocompleteModel": {
    "title": "Gemini 1.5 Flash (Autocomplete)",
    "provider": "gemini",
    "model": "gemini-1.5-flash-latest",
    "apiKey": "YOUR_GEMINI_API_KEY_HERE"
  }
}
💡 팁: gemini-1.5-flash는 응답 속도가 매우 빨라 실시간 탭 자동완성에 최적이며, gemini-1.5-pro는 복잡한 알고리즘 설계 및 대규모 리팩토링에 추천합니다.

다른 연동 방식도 궁금하신가요?

방법 2: 공식 'Gemini Code Assist' 확장

구글에서 직접 관리하는 공식 플러그인입니다. Google Cloud 프로젝트와 계정이 연동되어 있어 보안성이 매우 높습니다.

  1. VS Code 확장 검색창에 Google Cloud Code 또는 Gemini Code Assist 검색 후 설치.
  2. 좌측 하단 상태 표시줄의 Cloud Code - Sign In을 클릭해 구글 계정으로 로그인.
  3. 사용할 Google Cloud Project를 선택.
  4. Gemini Code Assist 토글을 켜면 에디터 내에서 실시간 자동완성 및 제미나이 챗봇 활성화.

방법 3: 'Cline' 에이전트 확장과 연동

명령어를 스스로 입력하고 테스트를 돌리며 에러를 잡는 에이전트 환경에 Gemini 1.5를 탑재하는 최신 방식입니다.

  1. 확장 탭에서 Cline(구 Claude Dev) 검색 후 설치.
  2. Cline 설정 탭(⚙️)에서 API Provider를 Google Gemini로 선택.
  3. Model 항목을 gemini-1.5-pro-latest 또는 gemini-1.5-flash-latest로 지정.
  4. Google AI Studio API Key를 입력 후 저장하여 파일 자동 생성 및 터미널 자동 실행 활용.

자주 묻는 질문 (FAQ)

연동 중 발생할 수 있는 주요 질문들을 정리했습니다.

네, Google AI Studio는 개인 개발자를 위해 매우 넉넉한 무료 티어(Free Tier)를 제공합니다. Gemini 1.5 Flash 및 Pro 모델 모두 분당 요청 수(RPM) 및 일일 요청 수(RPD) 한도 내에서 신용카드 등록 없이 완전 무료로 사용할 수 있습니다.
Google AI Studio 무료 티어의 경우 서비스 개선을 위해 익명화된 데이터가 활용될 수 있습니다. 만약 기업 규정이나 보안상 코드 비학습이 필수라면 유료 플랜(종량제 종량과금 결제 계정 연결)을 이용하거나 Google Cloud Platform(GCP) Vertex AI 및 Gemini Code Assist 기업 계정을 사용하는 것을 권장합니다.
무료 티어의 분당 요청 제한(15 RPM 등)에 도달했을 때 발생합니다. 모델을 응답 속도가 빠르고 쿼터가 더 넉넉한 gemini-1.5-flash로 전환하거나, 탭 자동완성(Autocomplete) 간격을 늘려주면 원활하게 동작합니다.
첫째, 100만~200만 토큰에 달하는 방대한 컨텍스트 윈도우로 대형 프로젝트의 수십 개 소스코드 및 기술 문서를 한 번에 입력해 일관성 있는 코드를 작성할 수 있습니다. 둘째, 무료 API 키로 비용 부담 없이 Copilot 수준의 기능을 누릴 수 있습니다.
